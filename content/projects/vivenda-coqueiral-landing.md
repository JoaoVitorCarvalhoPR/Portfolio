# Vivenda Coqueiral — Landing Page

A landing page built for the Vivenda Coqueiral real estate launch, a residential development in the Coqueiral neighborhood, Vila Velha - ES.

## Overview

A single-page site presenting 2 and 3-bedroom apartments, the leisure amenities, floor plans, and location — built with static HTML, CSS, and vanilla JavaScript, with WhatsApp as the primary conversion channel and Meta Pixel for ad tracking.

## Features

- Floor plan gallery across multiple unit types.
- Amenities and common-area showcase.
- Meta Pixel integration for campaign tracking.
- Fully responsive, from mobile to desktop.

## Stack

| Layer | Technology |
|---|---|
| Markup/Styling | HTML5, CSS3 |
| Interactivity | Vanilla JavaScript |

## Demo

The live site can go offline once the launch campaign ends, so a static copy is bundled with this portfolio and opens directly when you click the project card.
