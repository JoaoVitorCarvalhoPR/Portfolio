# Monte Tivoli — Landing Page

A landing page built for the Monte Tivoli real estate launch, a residential development in Cocal, Vila Velha - ES, developed for Veryon Imóveis.

## Overview

A single-page site presenting the development's concept, floor plans, leisure club (20 amenities), location, and a financing simulator — all built with static HTML, CSS, and vanilla JavaScript, with WhatsApp as the primary conversion channel.

## Features

- Interactive draggable location map highlighting nearby points of interest.
- Financing simulator with adjustable down payment and installment terms.
- Lead capture forms that hand off directly to WhatsApp with a pre-filled message.
- Fully responsive, from mobile to desktop.

## Stack

| Layer | Technology |
|---|---|
| Markup/Styling | HTML5, CSS3 |
| Interactivity | Vanilla JavaScript |

## Demo

The live site can go offline once the launch campaign ends, so a static copy is bundled with this portfolio and opens directly when you click the project card.
